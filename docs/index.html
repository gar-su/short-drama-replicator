使用说明与常见问题

使用步骤

  1. 登录：密码 admin（轻量门槛），GitHub Token 需对任务仓库 gar-su/short-drama-replicator 有读写权限。Token 只保存在浏览器本地，刷新页面自动预填。
  2. 提交任务：先选配音类型（AI配音 / 人工配音 / 都要），再输入素材名称（平台后台该素材的名称，例如 1472_KAHUI_YP_PT_LA103_7-9_980865_1564090_260602），回车或点「提交」。
  3. 等待处理：worker 每 5 分钟轮询一次任务仓库，看板卡片会经历 待处理 → 处理中 → 已完成 / 失败。
  4. 查看结果：完成后成片自动上传到平台，位于该素材的 {素材名}_复刻 文件夹，每个语种一个成片。

产出说明

  • 产出范围由提交时的配音类型决定：AI配音 只产 AI 配音版、人工配音 只产人工配音版、都要 两者都产。素材本身是配音版（非原版）或该剧没有所选类型的版本时，任务会失败并在卡片上提示。
  • 每个成片 1080×1920 竖屏，顶部为目标语种剧名、底部为该剧剧情总结，主体加固定片尾。
  • 文件名格式：{序号}_KAHUI_YP_{语种}_{剧码}_{集数}_{起止毫秒}_{日期}_AI复刻.mp4

常见问题

提交后要等多久？
取决于该剧有多少 AI 配音语种：语种多（如 16 个）通常 20–40 分钟，首次还会加上素材下载与转写时间。看板实时刷新，卡片停留在「处理中」即代表正常。
同一个素材能重复生产吗？
可以。重新提交会先清掉旧的 成功/失败 卡片，以本次生产为准，避免同名冲突。
任务卡在「处理中」很久不动怎么办？
worker 会自动回收超过 8 小时仍未完成的「处理中」任务，重排回「待处理」重新执行；正常较慢的任务不会被误伤。
「配音类型」三个选项有什么区别？
AI配音：只产出 AI 配音版语种（库名带 "AI"）；人工配音：只产出人工配音版语种；都要：两类都产出（同一语种可能同时有两类，成片数量会翻倍）。提交后卡片上会标注本次的配音类型。若该剧没有所选类型的版本，任务会失败。
为什么有些语种的成片是 608×1080 且没有片尾？
该语种片源本身就是这个分辨率和无片尾，属正常现象，不影响播放。
任务失败怎么办？
「失败」列会显示错误摘要。常见原因：素材名称有误、该剧无 AI 配音版、磁盘空间不足、网络超时。确认后可重新提交。
GitHub Token 安全吗？
Token 只保存在你自己的浏览器 localStorage，不会上传到任何服务器或写入代码仓库，请勿外发给他人。
